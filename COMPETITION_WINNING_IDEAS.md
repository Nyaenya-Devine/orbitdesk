### IDEA 2: Gamified Progress & Realistic SLA + Final Assessment Saved (Duolingo + Coursera + Linear + Stripe + Salesforce + Zendesk)

**What was basic before:**
- No progress saved, refresh = lost. No XP, no levels, no assessment at end. SLAs same for all clients, not realistic (Bloom 9-5 should wait until next business day, not 24/7).

**What is finest now v3.0:**
- **Progress saved in localStorage:** Every ticket resolved, every call handled, CSAT, QA, SLA compliance, communication scores, XP, level, badges, history — all saved automatically with `saveProgress()` and loaded with `loadProgress()`. Session ID `sess_abc123_171...` for tracking. Survives refresh, for assessment at end.
- **Gamification like Duolingo:**
  - **XP:** Resolve ticket +10-30 XP (breach -10 XP, QA≥90 +30 XP, QA≥75 +20 XP, client language +10 XP), resolve conflict +15 XP, call handled +10-40 XP (score≥80 +40 XP). 
  - **Level:** Level = floor(XP/100)+1, shown in header Lvl 3 • 250 XP, progress bar to next level.
  - **Streak:** Days in a row, 🔥
  - **Badges:** First Fix 🛠️, Problem Solver 🔧 (5 tickets), Support Hero 🦸 (10), CSAT Champion ⭐ (4.5), QA Master 🎯 (90%), SLA Guardian ⏱️ (95%), Voice Pro 📞 (1 call), Call Master 🎙️ (5 calls), Empathy Expert 💜 (80), Streak Keeper 🔥 (3 days) — like Duolingo.
- **Realistic SLA by client business hours (Salesforce-style):**
  - **NovaTech Enterprise 24/7:** P1 60min, P2 4h, P3 8h, P4 24h — always counts, even midnight.
  - **Bloom SMB 9-5 Mon-Fri:** P1 4h business hours, P2 8h, P3 24h, P4 48h — if ticket created outside 9-5 or weekend, waits until next business day 9am Monday. Realistic, not 24/7. Tag `business-hours` vs `24-7` shown.
  - **Apex Regulated Strict SEC-2024-07:** P1 1h, P2 2h, P3 4h, P4 8h — strict, breach = compliance violation.
  - **Escalation at 50% time left:** Like Salesforce, escalate before breach.
  - **SLA compliance %:** Resolved / (Resolved+Breached) *100, shown in assessment.
- **Final Assessment Report — Saved for Influx Interview:**
  - **Grade A+ to C:** Overall score = (CSAT*20 + QA + SLA + avgCommunication)/4. A+ ≥90 Influx Ready Hire Immediately, A ≥80 Excellent Senior Support Level, B+ ≥70 Good Ready for Influx with minor coaching, B ≥60 Satisfactory Needs practice, C <60 Needs Improvement.
  - **Radar:** Level & XP with progress bar, CSAT & QA, Communication breakdown (empathy, clarity, technical, fluency, client lang with bars), SLA realistic balancing, Badges, Recent history saved (timestamp, action, ticket code, score) for assessment.
  - **Why unique:** No other simulator saves progress for final assessment with XP/levels/badges + realistic SLA business hours + grade for Influx. If competition, you win because you show growth, not just one-time fix.

**How it solves your complaint:**
- Before: "Students progress should be saved for assessment at end" + "balance SLAs in better realistic way" → Now: Progress saved auto, XP Level badges, realistic SLA by client business hours, final report with grade A+ to C for Influx.

### IDEA 3: Session Management + Toast Grouping + Instructor Mode (Figma + Loom + ServiceNow + Slack + Pendo)

**What was basic before:**
- Notifications stuck: "Enabled BitLocker for priya.sales@novatech.com — Protection On, key escrowed to Entra ID — correct tool used ✓" repeated 3 times, stuck on screen making working hard.
- No session management, no instructor view.

**What is finest now v3.0:**
- **Toast System Grouped, Not Stuck (Slack + Pendo style):**
  - **Grouping:** Same groupKey (e.g., `bitlocker`, `signin-logs`, `sync`) grouped — if 3 BitLocker toasts, shows "Enabled BitLocker... (x3) Grouped — swipe to dismiss all" instead of 3 separate stuck toasts.
  - **Limit 3 visible:** Only last 3 groups shown, +N more grouped indicator, max 10 total, oldest removed.
  - **Progress bar:** Bottom 0.5px bar animates 100% → 0% over duration (3000-5000ms), auto-dismiss on complete.
  - **Swipe to dismiss:** Drag x >100 → dismiss, with gradient hover hint, close button ✕.
  - **GroupKey:** `open-INC-...`, `assign-...`, `resolve-...`, `checklist-logs`, `bitlocker`, `rdp-...` — prevents spam.
  - **Why unique:** No more stuck notifications — grouped, progress bar, swipe, limit. Solves your exact complaint.
- **Session Management (Figma + ServiceNow):**
  - **Session ID:** `sess_abc123_171...` with start time, saved in localStorage `orbitdesk_session_<id>`, for audit trail.
  - **Recording + Audit log:** Every action logged with timestamp, ticket code, score — history saved for assessment, like ServiceNow audit.
  - **Instructor mode (future):** Instructor can join session, see cursor, leave Loom video feedback, see progress live — Figma multiplayer + Loom.
  - **Ticket dependencies:** Fixing BitLocker unblocks Teams (future ServiceNow CMDB style) — realistic.
- **Why unique:** Toast grouping + swipe + progress bar + session ID + audit log + history saved — no other simulator does this finest detail. If competition, you win because UX is polished, not stuck.

- Before: "Enabled BitLocker for priya.sales@novatech.com — Protection On... this notifications are stuck on screen making working hard" → Now: Grouped (x3), progress bar, swipe to dismiss, limit 3, not stuck. Session managed, progress saved.
