## What it is

OrbitDesk simulates a Modern Workplace support shift. You handle tickets, investigate logs, apply fixes in admin portals, manage calls, and collaborate with your team — all in the browser, no real credentials, no backend required for core training.

Designed for learning and interview preparation — not a replacement for production systems.

## Highlights

**Operations Training**
- Ticket queue with priorities, SLA tracking, and client context
- Investigation tools and admin portal simulations
- Remote desktop with audit logging

**Team Collaboration**
- Class-based workforce — team lead can call agents in same class
- Presence: online, in-call, offline — like Teams/Slack
- Coaching and escalation flows

**Learning**
- Student and Expert modes
- Progress, levels, and assessment report
- Local-first, privacy-focused — no tracking
